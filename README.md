# 小说写作辅助

帮你写长篇小说，记住所有设定，追踪角色、物品、伏笔、时间线，确保几百万字也不会自相矛盾。

## 能做什么

- **设定管理**：角色、物品、地点、势力、时间线、伏笔自动追踪
- **一致性检查**：检测角色位置冲突、时间线错误、物品归属问题
- **大纲管理**：全书大纲 → 卷大纲 → 章节大纲
- **章节写作**：字数控制、设定自动更新、冲突提醒
- **伏笔追踪**：埋下的伏笔不会忘，提醒你揭晓
- **多本小说**：配置隔离，随时切换

## 快速开始

### 1. 新建小说

```
新建小说 我的第一本书
```

我会问你：
- 小说类型
- 保存位置（语雀/本地）
- 人称、视角、文风
- 每章字数范围
- 类型相关设定（修炼体系、势力关系等）

每道题都可以输入「够了」跳过，之后用「补充设定」继续。

### 2. 写大纲

```
写大纲
```

我会问你要写到什么程度：
- 卷级：每卷主题
- 章节级：每章内容

### 3. 写章节

```
写章节 1
写章节 第一章 初入江湖
```

流程：
1. 我读设定
2. 生成章节大纲给你确认
3. 你确认后我开始写
4. 写完自动更新设定

**字数提醒**：
- 到 3500 字提醒进度
- 到 4000 字提醒上限（可继续写）
- 低于 2000 字会提示

### 4. 查设定

```
查设定 张三          # 查角色
查设定 神剑          # 查物品
查设定 王城          # 查地点
查设定 伏笔          # 查所有伏笔
查设定 时间线        # 查时间线
```

### 5. 查冲突

```
查冲突
```

自动检测：
- 角色位置冲突
- 时间线冲突
- 物品归属冲突
- 已死角色出现

### 6. 其他命令

```
状态              # 当前进度
回溯 10           # 查第10章发生什么
更新设定          # 手动更新设定
补充设定          # 继续未完成的设定问答
切换小说 书名     # 切换到另一本小说
更新图            # 手动更新关系图
```

## 存储方式

### 语雀存储

设定和正文分开两个知识库：

```
正文知识库
├── 第一章 标题
├── 第二章 标题
└── ...

设定知识库
├── 角色设定/
│   ├── 主角组/
│   ├── 反派组/
│   └── 配角组/
├── 物品设定/
├── 地点设定/
├── 势力设定/
├── 时间线/
├── 伏笔追踪/
├── 大纲/
└── ...
```

### 本地存储

```
小说名/
├── 正文/
│   ├── 第1章.md
│   └── ...
├── 设定/
│   ├── 角色设定/
│   ├── 物品设定/
│   └── ...
└── config.json
```

## 设定追踪

### 角色

记录：
- 基本信息（姓名、年龄、阵营）
- 外貌描述
- 性格特点、说话风格
- 位置与状态（当前在哪、受伤情况）
- 目标（当前目标、目标变化历史）
- 关系（与其他角色的关系变化历史）
- 背包（物品、装备）
- 技能（等级、获得历史）
- 情绪变化
- 状态历史（健康→受伤→恢复）

### 物品

记录：
- 基本信息（名称、类型、重要性）
- 外观描述
- 特性与能力
- 当前持有者
- 流转历史（A→B→C）
- 隐藏属性

### 地点

记录：
- 基本信息（名称、类型、势力归属、危险等级）
- 特点描述
- 相关角色（谁在这）
- 发生事件
- 探索进度

### 伏笔

记录：
- 优先级（核心/普通/彩蛋）
- 埋设章节
- 内容
- 预期揭晓章节
- 状态（进行中/已揭晓）
- 揭晓情况

每次写章节后提醒未揭晓的伏笔。

### 时间线

记录：
- 世界观历法
- 每天发生的事件
- 时间跳跃标记

## 一致性检查

自动检测冲突：

**位置冲突**：
```
角色A第10章在X城，第12章在Y城，没写移动过程
→ 可能是冲突
```

**时间线冲突**：
```
第10章是第5天，第12章是第3天
→ 时间倒流
```

**角色状态冲突**：
```
角色B第10章已死亡，第15章又出现
→ 检查是否冲突
```

**物品冲突**：
```
物品「剑」第10章被B获得，第12章还在A背包里
→ 检查归属
```

## 写作提醒

### 写章节时

- 3500 字提醒进度
- 4000 字提醒上限
- 2000 字提醒下限
- 写完自动更新设定
- 发现冲突立即提示

### 角色首次出现

自动询问：
- 性别、年龄
- 阵营
- 外貌描述（可选）
- 性格特点（可选）

### 角色状态变化

写完章节后提醒：
```
角色A等级变化：筑基期→金丹期（第20章突破）
```

### 关键节点

检测到问题时提醒，不定期提醒。

## 完本总结

小说完结时自动生成：
- 总字数、总章节
- 角色统计
- 伏笔统计（已揭晓/未揭晓）
- 时间线跨度
- 势力、地点、物品统计

## 多本小说

想开新书：

```

```

切换小说：

```
切换小说 第一本书
切换小说 D:/小说/第一本书/config.json
```

配置隔离，互不影响。

## 注意事项

### 必须知道的

1. **改了语雀设定要告诉我**：说「设定已更新」，我会重新读取
2. **初始化时耐心回答**：设定越完整，后面越不容易出问题
3. **冲突早处理**：发现问题立即处理，不要积累

### 我会询问的节点

- 创建知识库前
- 创建设定文档前
- 写章节前（大纲确认）
- 写章节后（设定变更确认）
- 新角色出现时
- 检测到冲突时
- 设定变更影响较大时

### 我不会默默做的

- 不会默默更新设定（会问你确认）
- 不会默默处理冲突（会报错让你决定）
- 不会默默创建配置（会发给你确认）
