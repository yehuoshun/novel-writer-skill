# 小说写作辅助 (novel-writer-skill)

一个用于 OpenClaw 的小说写作辅助技能，帮你管理长篇小说的设定、大纲和章节写作。

## 核心能力

- **设定管理**：角色、物品、地点、势力、时间线、伏笔自动追踪，设定冲突检测
- **CHANGES 变更声明协议**：每章写完自动声明变更，AI 自动更新设定，保持一致性
- **9 门禁校验**：禁用词 / AI句式 / 心理外化 / 节奏 / 对话 / 结尾 + 引用校验 + 一致性校验 + 描写一致性 + 未知实体检测 + 蓝图出场合规
- **事实快照**：集中管理所有实体的当前状态，解决长篇小说 Big Doc 问题
- **大纲管理**：全书 → 卷 → 章节三层大纲，自动标注关键节点
- **爽点/钩子/情绪追踪**：追踪爽点间隔、钩子类型强度、情绪曲线
- **多本小说**：配置隔离，随时切换
- **存储方式**：支持语雀 / 本地 / 同时保存

## 快速开始

```
新建小说 我的第一本书
```

然后按提示回答类型、存储方式、人称、文风等设定。每道题可输入「够了」跳过。

## 命令一览

| 命令 | 用途 |
|------|------|
| `新建小说 [书名]` | 初始化新项目 |
| `切换小说 [书名]` | 切换到另一本书 |
| `写大纲` | 生成全书/卷/章节大纲 |
| `查大纲 [章节号]` | 查看大纲详情 |
| `写章节 [章节号]` | 写指定章节（自动走 CHANGES+门禁） |
| `续写` | 继续写未完成的章节 |
| `回溯 [章节号]` | 查看某章详情 |
| `状态` | 当前进度概览 |
| `查设定 [实体名]` | 查询角色/物品/地点/势力 |
| `查冲突` | 检测全部设定冲突 |
| `更新设定` | 手动更新设定 |
| `更新图` | 更新 Mermaid 关系图 |

## 存储结构

### 本地
```
小说名/
├── 正文/ 第1章.md, 第2章.md ...
├── 设定/
│   ├── 角色设定/ 物品设定/ 地点设定/ 势力设定/
│   ├── 时间线/ 伏笔追踪/ 大纲/ 关键对话/ 世界观/
│   ├── 爽点追踪/ 钩子追踪/ 情绪曲线/
│   ├── 变更日志/ changes/
│   └── 状态快照.md
└── config.json
```

### 语雀
正文和设定分开两个知识库，语雀内用 TITLE 节点做分组目录。

## 配置文件

放在 `configs/[小说名].json`，参考 `configs/example.json`。

## 技术细节

- **CHANGES 协议**：每章末尾的固定格式变更声明，AI 自动解析
- **9 门禁**：6 道写作质量门禁 + 引用/一致性/描写/实体/蓝图出场校验
- **事实快照**：集中存储当前态，历史在 changes/ 目录下增量保存
