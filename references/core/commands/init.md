# 命令详解：初始化相关

> 何时加载：新建 / 切换小说、看状态时。SKILL.md「命令列表」只留一句话，这里是完整流程与判据。


## 新建小说
```
新建小说 [小说名]
```
**流程**：先问清 8 件事（类型／存储方式／人称／视角／文风／节奏／每章字数／题材专属设定）→ 生成配置给你确认 → 建设定目录 → 全书大纲+卷大纲+细纲含蓝图出场清单（**不完成不进写章节流程**）→ 书名查重 → 生成简介。每步的问答细节见 [new-novel-flow.md](../../core/new-novel-flow.md)，设定文档模板见 [setup-templates.md](../../core/setup-templates.md)。

**设定问答中途停止**：用户说「够了」就用已收集的信息生成设定，并提示「后续可用『补充设定』或『更新设定』」。

## 切换小说
```
切换小说 [小说名]
切换小说 [配置文件路径]
```
**流程**：
1. 校验配置文件是否存在、格式是否正确
2. 清除上一个小说的设定缓存（上下文隔离）
3. 加载新小说配置
4. 提示切换成功

**配置校验**：
- 检查必需字段：`info.name`、`save_location`
- 检查存储路径有效性
- 若配置损坏或缺失，报错并提示修复路径
- 完整兜底校验可运行 `node scripts/validate-config.js <配置文件>`（schema 枚举约束 + 8 条扩展逻辑，含大纲先行等跨字段检查）

## 状态
```
状态
```
显示当前进度：
- 当前写到第几章/第几卷
- 总字数
- 未揭晓伏笔数量
- 待处理设定冲突（如果有）
- 最近爽点间隔（正常 / 连续X章无爽点 / 同类型爽点连用X次）
- 最近钩子：章首{类型}({强度}) / 章尾{类型}({强度})
- 最近情绪：最高{情绪}({强度})（连续X章平稳）
- 最近更新
