# 命令详解：写作相关

> 何时加载：写章节 / 续写 / 回溯时（每次动笔前）。这里只有**阶段骨架与动笔前必读**；阶段三的门禁判据在 [writing-gates.md](writing-gates.md)，阶段四的落地回写在 [writing-publish.md](writing-publish.md)，按需接着读。

## 写章节
```
写章节 [章节号]
写章节 [章节标题]
写章节          # 不指定时，默认写最新章节（info.current_chapter + 1）
```
**流程**：

**阶段一：准备**
1. 校验配置文件有效性
2. 定位续写位置 + 读交接包：先跑 `node scripts/next-chapter.js <config.json>`——它把「已发布到第几章（账本）/ 正文目录到第几章 / 下一章该写第几号 / 交接包内容 / 快照有没有欠账」一次列出来，出现 `⛔` 先处理（多为上一章 CHANGES 没回写快照，发布会被 exit 4 拦住）再动笔；同一份输出里还有**伏笔账**（`## 伏笔状态` 每条未了结伏笔离「该推进」还剩几章：长线 5 章起提醒 / 10 章逾期，短线·误导 2/4，彩蛋 3/6；🔴 逾期、🟡 快到线，已回收的不算）——动笔前先看它，能顺手推一条就写进本章细纲，别等门禁在写完后再喊；再读 `状态快照.md` 顶部的 `## 下章交接包`（上一章留下的交接单）与快照正文确认当前所有实体状态（不读历史）
3. 按需加载相关设定（本章涉及的角色/地点/物品的详细档案；**涉及多地相对位置时加载「地理方位」表**核对，2026-10-12 补）
4. 参考本章细纲（含蓝图出场清单），必要时加载 [references/outline/outline-arrangement.md](../../outline/outline-arrangement.md) 和 [references/outline/expectation-techniques.md](../../outline/expectation-techniques.md)
   - ⚠️ **细纲缺失禁止开写**：设定中无细纲文档（本地：`设定/大纲/细纲/` 无文件；语雀：`大纲/细纲` 分组无 DOC）时，先执行「写大纲」生成全书大纲+细纲（含蓝图出场清单），再回来写章节——不允许跳过大纲直接开写
   - **校对本草对白体例（2026-10-12 补）**：先读本书近 1-2 章正文，确认对白写法（如本书=「说，…」无引号体，「」仅用于引述片段；或引号体），照本书体例写——勿套用通用引号体（实弹：第22章误用「」引号体，全章改写）
   - **细纲/蓝图缺本章行（2026-10-12 补）**：细纲存在但蓝图清单无本章行 → **先补该行**（含必出场角色/势力/地点 + 戏分）再写；蓝图「必出场势力」若本章悬疑设计刻意不点名，填「无」或与正文一致的表述，勿写设定标签词（实弹：第22章蓝图要求「外部势力」出场但正文刻意不点名 → 校验失败）
5. 生成这章大纲（标注：核心事件、本章爽点类型、章首钩子类型、章尾悬念 + **每个核心事件的场景字数配额**，Σ 落在 `writing.chapter_words` 目标区间、一般 2800-3400）
   - **字数配额脚手架（2026-10-12 补）**：配额是防「骨架化欠量」的**下限脚手架**，不是硬卡（硬卡会逼出注水）；允许 ±15% 浮动，超上限也提示
6. 发给你确认
7. 你确认/修改

**阶段二：写作 + 变更声明**
8. 写正文（**动笔前先对阶段一的场景字数配额；全章写完先跑 `scan-text-health` 字数门禁，欠量按缺口场景补（对话轮次/厚段/细节），禁整篇注水**——2026-10-12 第22章实弹：初稿骨架化只 1769 字，挂脚本才发现；实时字数提醒：3500字提醒进度，4000字提醒上限，不低于2500字；排版规范：全角标点“ ”、段首缩进两全角空格、不用半角标点、**叙述层破折号≤3处且仅限对话打断（规则见 [references/quality/anti-ai-gates.md](../../quality/anti-ai-gates.md)「破折号限额」）**、**精确数字不枚举成簇（≥3处即模糊化）**、**对仗陈述句不≥2处**、**章尾不用宣言句**（规则见 [references/quality/anti-ai-gates.md](../../quality/anti-ai-gates.md)「金句密度限额/精确数字成簇/工整对仗句」），见 [references/quality/anti-ai-gates.md](../../quality/anti-ai-gates.md) Gate 5；**2026-10-12 P0 落地：写完立刻自查破折号与字数——`node scripts/scan-text-health.js <本章.md> <config>` 一条命令同时出字数（低于下限打回）与破折号计数（超 3 打回），欠量/超限当场补，别等门禁阶段**）
   - 参考 [references/style/style-modules.md](../../style/style-modules.md) 确保文风一致
   - 参考 [references/hook/hook-techniques.md](../../hook/hook-techniques.md) 确保钩子到位
9. **AI 必须在正文后输出 `---CHANGES---` 变更声明块**（见下方「CHANGES 变更声明协议」；**2026-10-12 P0 落地：CHANGES 块从正文实际改动提取、对照正文逐条核对（角色状态/移动、物品流转、地点/势力状态、伏笔推进、交接包），不凭记忆手写**——第23章实弹：手写 CHANGES 里陈长老引文与正文漂移，门禁阶段才发现）
   - ⚠️ **CHANGES 块行首必须顶格**：正文自然段首行缩进两全角空格是排版要求，但 `---CHANGES---`、`---END CHANGES---` 及块内**每一行都不能带全角空格缩进**——parse-changes.js 按行首精确匹配，一旦缩进即报「No CHANGES block found」打回（2026-10-10 实弹暴露）

**阶段三：12 门禁校验**（全部自动，不通过则打回 AI 重写）

> 逐条判据、**顺序铁律（门禁必须在阶段四状态回写之前跑）**、阶段三收尾（结构化报告 + 双模型复核）、**交付前检查**、门禁结果输出格式、验收分级 → 全部在 [writing-gates.md](writing-gates.md)。**这一步不许省：门禁全绿 ≠ 能交付，交付前检查必须做完再落地。**

- **门禁 10 写作质量（Gate 1–6）**：文本健康 / AI 句式 / 心理外化 / 节奏 / 对话 / 结尾 —— `scripts/scan-text-health.js`（Gate 1 + 字数门禁）+ `scripts/scan-ai-tells.js`（Gate 2–6 可规则化子集，只提示）
- **门禁 11 引用校验**：CHANGES 声明的角色/地点/物品/势力 ID 必须已建档（零容忍）
- **门禁 12 一致性校验**：移动 / 已死 / 地点状态 / 物品归属 vs 上一章快照
- **门禁 13 描写一致性**：正文外貌描写 vs 快照外貌表 / 角色档案
- **门禁 14 未知实体检测**：正文冒头但 CHANGES 未声明，容错 ≤5，仅警告
- **门禁 15 蓝图出场合规**：细纲蓝图必出场实体是否真出场
- **门禁 16 伏笔闭环**：伏笔动作与状态机一致（含档案/快照双写一致性）
- 门禁 11–16 本地模式一条命令兜底：`node scripts/check-consistency.js <状态快照.md> <本章.md> <设定目录> [细纲.md]`

**阶段四：落地 + 状态回写**

> 落地（本地 / 语雀 / 双写）、双写对账、全书体检、CHANGES 回写、冲突检测、配置与章节摘要更新 → 全部在 [writing-publish.md](writing-publish.md)，按条目号 17 → 23 顺序走。**改版备份铁律也在那里，动正文前先看。**

CHANGES 协议、写作技巧速查、字数节奏参考等详见 [references/core/changes-protocol.md](../../core/changes-protocol.md)。

## 续写
```
续写
```
继续写当前未完成的章节。

**流程**：
1. 校验配置文件有效性
2. 恢复上下文：
   - 读取下章交接包（`状态快照.md` 顶部 `## 下章交接包`）
   - 读取当前章节状态（`info.current_chapter`）
   - 读取已写内容的摘要（本地：`设定/变更日志/`；语雀模式见手册 6.7）
   - 按需加载相关设定（当前场景涉及的角色、地点）
3. 问：「写到哪了？/ 当前场景是？」
4. 你告诉我场景/情节
5. 继续写
6. 写完后按写章节流程的阶段二～四走（CHANGES → 12 门禁 → 落地 → 状态回写）

## 回溯
```
回溯 [章节号]
```
显示某章详情：
- 摘要
- 出场角色
- 发生地点
- 关键事件
- 爽点（类型+铺放比）
- 钩子（章首/章尾类型+强度）
- 情绪基调（强度链）
- 伏笔
- 时间线
