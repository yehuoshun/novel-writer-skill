# 新建小说流程

首次建书时按这 14 步走一遍；中途用户说「够了」就用已有信息生成，并提示后续可用「补充设定」「更新设定」。

## 新建小说
```
新建小说 [小说名]
```
**流程**：
1. 问：「小说类型是？」
2. 问：「保存到哪？A 语雀 B 本地 C 语雀+本地」（正文和设定同一处；**推荐 B 本地**，语雀为可选项）
   - A 语雀 → 问：「知识库ID或namespace（二选一即可）」（正文+设定同一个知识库；repo 标识用数字 id 或 namespace 均可）
   - B 本地 → 问：「正文保存路径」（默认：./小说名/正文/）「设定保存路径」（默认：./小说名/设定/）
   - C 语雀+本地（双写）→ 语雀知识库（单个）和本地路径都问，正文/设定两处都写
3. 问：「人称？（第一人称/第三人称）」
4. 问：「视角？（单主角/多主角/群像）」
5. 问：「文风？（古风/现代/幽默/严肃）」（选定后映射风格模块：古风→奇幻玄幻、现代→现实世情、幽默→幽默/轻小说、严肃→悬疑/推理/恐怖，加载指引见 [references/style/style-modules.md](../style/style-modules.md)）
6. 问：「叙事节奏？（快节奏/慢热/细腻）」
7. 问：「每章字数范围？（默认2500-4000）」
8. 问：「小说类型相关设定」（每道题标注「可随时输入"够了"跳过」）
   - 玄幻/修仙：修炼体系、等级设定...
   - 都市：势力关系、职业设定...
   - 科幻：科技水平、世界观...
9. 生成配置文件，发给你确认
10. 你确认后，创建设定文档模板
11. 根据存储方式创建设定目录结构：
    - **语雀模式 / 双写（both）**：调用语雀 API 自动创建目录分组并回写 UUID——22 项分组映射、content 首建、旧库补建、快照 DOC 特殊处理见 [references/integrations/yuque-integration.md](../integrations/yuque-integration.md) 第 3 节，MCP/裸 API 调用细节见第 5 节
    - **本地模式**：在设定路径下创建完整的本地目录树（角色设定/主角+反派+配角+已故、物品设定、地点设定、势力设定、等级体系、时间线、伏笔追踪、爽点追踪、钩子追踪、情绪曲线、大纲/细纲、关键对话、世界观、Mermaid关系图、变更日志、状态快照.md；`changes/` **可选**——旧布局兼容，新书可不建，见阶段四 17 条）
12. 开始写全书大纲（**必完成**：全书大纲+卷大纲+章节细纲含蓝图出场清单；不完成不进写章节流程）
13. **书名查重（番茄站内，上线前必做，2026-10-11 老板定）**：按 [references/opening/book-name-vetting.md](../opening/book-name-vetting.md) 查**番茄站内**同名/近名——同名必换、近名提醒、设定撞车提醒不阻断；**现阶段只审查番茄**（非番茄平台同名不列入）；改名保留「分类关键词+核心卖点」，长名转「又名」；改名后全库同步（配置 info.name / 简介 / 大纲 / 知识库名 / 本地 / 记忆）（实弹：《炼气一万年》番茄近名 2 本 → 改《炼气万古》）
14. **生成简介（含发布 tag）**：按 [references/opening/description-tags.md](../opening/description-tags.md) 生成简介正文 + 番茄 tag 块（**目前仅支持番茄小说 tag**：主分类必选×1、主题/角色/情节各≤2，选项列表与决策准则见该文档；其他平台待实弹需求再扩展）；简介落库——本地：`设定/简介.md`；语雀/both：另见手册第 3.5 节

**设定问答中途停止**：
- 用户输入「够了」→ 用已有信息生成设定
- 提示：「后续可用"补充设定"或"更新设定"」
