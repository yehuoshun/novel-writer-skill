# 完本总结模板

小说完结时按这份模板交一份总结。**数字优先从脚本取**，不要手估：

- `node scripts/book-report.js <config.json> --json` → 爽点类型分布、钩子覆盖率与强度分布、情绪峰值/谷值/最大差、字数与跨度
- `设定/状态快照.md` 的 `## 伏笔状态` → 伏笔总数/已回收/已废弃/未处理；`## 角色状态` → 角色与已故统计
- `node scripts/publish-status.js <config.json>` → 实际发布章数与总字数（以账本为准，不以草稿为准）
