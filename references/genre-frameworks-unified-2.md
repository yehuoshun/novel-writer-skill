# 题材框架大全（二）

> 核心梗解析与运用、事业线/爱情线设计

## 核心梗解析与运用

### 什么是核心梗

- 核心梗 = 你的金手指最核心的使用方式 + 读者最想看的爽点模式
- 它是你这本书区别于其他同类书的关键
- 书名、简介、金手指、主线都应围绕核心梗设计
- 金手指是工具，核心梗是这个工具最有趣的使用方式
- 例：贡献毒计（金手指运用方式）+ 震惊女帝/老朱（爽点模式）= 核心梗
- 核心梗可以平替：女帝可以换成朱元璋、嬴政，背景可以任意置换

### 从脑洞到核心梗

1. 先有一个待加工的脑洞
2. 从脑洞中挖掘出核心卖点
3. 根据核心卖点定好主线
4. 金手指配合主线衍生

### 核心梗的运用

- 核心梗不是一个点，而是一套可循环的运用模式
- 每个剧情单元都是核心梗的一次变奏
- 变奏的不是核心梗本身，而是使用场景、对象、条件
- 如果剧情脱离了脑洞和金手指，脑洞就没用上
- 新手至少要保证整本书紧扣核心卖点
- 挂羊头卖狗肉（书名暗示的核心梗与实际内容不符）是大忌
- 例：书名暗示"贡献毒计"，内容却写成"杀鬼子就变强"——核心卖点偏了

### 核心梗与主题

- 绝大多数小说都有明确的主旨，防止小说偏离核心
- 核心梗 + 题材背景 = 你的定位
- 同一个核心梗可以套用不同题材
- 选题材时要考虑核心梗在该题材下的表现力

### 核心梗的检验

- 自检三问：
  1. 读者翻开你的书，最想看的是什么？（这就是你的核心梗）
  2. 每个剧情单元是否都在展示核心梗？
  3. 核心梗的爽点模式是否能循环使用？
- 常见问题：
  - 核心梗太多 = 没有核心梗
  - 核心梗太弱 = 读者没有追读动力
  - 核心梗用完 = 需要升级或变奏，不能生硬重复

### 核心梗的本质——情绪链条

- 核心梗是一个完整的情绪链条：由特定的情绪期待和情绪满足构成
- 吸引读者的本质是情绪点，核心梗对读者的吸引力必须时时刻刻都在
- 读者翻开你的书，是被情绪期待拉住的，不是被设定拉住的

**三代核心梗模型**

- 一代核心梗——主题：小说最底层的中心思想和立意，给小说赋予目标和方向，防止偏离。主题不明确 = 连人物和剧情的意义都写不出来，文字干巴巴。例：西天取经、普度众生——主题赋予故事方向
- 二代核心梗——题材核心：每个题材都有其核心，把握核心才能掌握边界感和氛围感。分析方法：看同题材火的书，它的核心卖点和核心情绪是什么。跑偏信号：都市恋爱文的主角突然穿越去玄幻世界杀怪升级
- 三代核心梗——核心情绪：扮猪吃虎、弥补遗憾、改变命运、退婚流、后悔流等，最好展现读者需求与情绪的形式。三代核心梗的作用：筛选读者 + 提升戏剧性。一本成功的小说通常由2-4条核心梗融合归一

### 核心梗的循环与贯穿

- 每章必备要素（三选一）：
  1. 拥有核心梗相关的期待点
  2. 拥有核心梗相关的爽点
  3. 介于核心梗的期待点和对应爽点之间
- 断期待的判断：某一章既没有核心梗的期待点也没有爽点，前一个爽点已结束，本身又没有拉起新的期待感 → 读者觉得书失去了"灵魂"，开始弃书。核心梗相关的期待感可以断开，但需要用其他期待感来补位
- 不断循环型：每个一级结构运行一次，变奏的是场景、对象、条件
- 只运行一次型：围绕一个核心情绪分阶段推进，每个阶段有独立的期待点和爽点。例：禁忌之恋可拆为"自我认知→告白→发糖→隐藏→摊牌"五个阶段

### 核心梗与题材匹配

- 核心梗 + 题材背景 = 你的定位
- 同一核心梗可套用不同题材，选材时要考虑核心梗在该题材下的表现力
- 写历史文的核心是改变历史人物命运，脱离这个就跑偏了
- 跨题材微创新：把已有核心梗换个题材就是新体验，同样的节奏、类似的金手指，世界观一换，新鲜感就来了
- "学我者生，似我者死"——学了优点拿走换个地方放出来可能就爆
- 网文折腾这么多年，本质是新瓶装旧酒，难也难在这里

### 核心梗的实战技巧

- 从脑洞到核心梗的路径：先有待加工的脑洞 → 从脑洞中挖掘核心卖点 → 根据核心卖点定主线 → 金手指配合主线衍生
- 拆书分析核心梗：先明确该书的一代（主题）、二代（题材核心）、三代（核心情绪），分析该书的期待感和爽感分布，区分与核心梗相关和不相关的。白金大神的书通常有2-4条核心梗融合，需要逐层拆解
- 核心梗的检验清单：
  - 读者翻开这本书最想看什么？（核心梗）
  - 每个剧情单元是否都在展示核心梗？
  - 核心梗的爽点模式能否循环使用？
  - 有没有挂羊头卖狗肉（书名暗示的核心梗与实际内容不符）？
  - 全文每一章是否满足三要素（期待点/爽点/中间态）中的至少一个？

### 核心梗的迭代与进化

- 理解核心梗的迭代，就能分析出优秀小说的核心运作方式和优缺点
- 别人的优点你该怎么学习，缺点你该如何改善
- 研究题材时不会走冤枉路，写文有了进步的方向和目标
- 一本小说的核心通常由几代核心梗融合而成
- 白金大神的书通常有2-4条核心梗融合归一，拆解时需逐层分析
- 拆书时要把期待感和爽感区分为：与核心梗相关的 / 不与核心梗相关的
- 故事构型（板子）中，核心梗相关的期待感和爽感分布是重要组成部分
- 核心梗与读者需求紧密相关，核心梗就是读者最需要的东西
- 写书时要让核心梗与读者需求始终保持一致
- 避免陷入自嗨而偏离核心梗、偏离读者需求
- 时刻有意识：读者看我的书前已知什么，看完设定已知什么，看完剧情已知什么

### 核心梗的常见误区

- 新手高频错误：
  - 核心梗太多 = 没有核心梗，什么都想写等于什么都没写
  - 立意不明确 = 连人物和剧情的情绪目标都没有，文字干巴巴
  - 纯装逼打脸没有主题 = 剧情本身没有意义
  - 核心梗用完不升级 = 生硬重复，读者审美疲劳
- 挂羊头卖狗肉：书名暗示的核心梗与实际内容不符是大忌
- 核心梗的认知偏差：新人对核心梗、核心卖点、核心情绪了解不透彻，容易分析错误。取巧方法：不理解理论时就先用本能写"我觉得这样写很爽"，写完再拿理论印证。理论辅助理解已有作品为何受欢迎，但未必对从零创作有帮助。不要先拿理论打算按理论设计桥段，容易吃力不讨好

## 事业线/爱情线设计

> 核心原则：事业线是长篇的骨架，爱情线是藤蔓。天花板取决于事业线的质量，但爱情线写好了能极大提升读者粘性。

### 事业线设计

**事业线是升级线**

- 都市商业文：经商=修炼，事业线就是升级线
- 学霸文：学习=修炼
- 修仙文：修炼本身就是事业线
- 无论什么题材，事业线的本质都是"主角从弱变强的过程"

**事业线的循环**

- 每个事业阶段要有明确的目标和对手
- 完成一个阶段后，下一个阶段的难度要升级
- 事业线的天花板决定了整本书的天花板

**没有事业线时怎么办**

- 抽取一段具有广泛共鸣的人生主线（高中、大学最有效）
- 将感情线当藤蔓依附在人生主干上生长
- 高中和大学是共鸣最广泛的人生主线
- 这也是为什么狗粮文基本都围绕校园写

### 爱情线/后宫线设计

**后宫文的处理**

- 女主设定在开书前就设计好方向
- 每个女主要有清晰的差异化特征（家庭背景、性格、与主角的关系类型）
- 不能让读者觉得几个女主可以互换
- 多女主间的关系要有化学反应，不只是跟主角的关系

**女主差异化设计**

- 家庭圆满型 vs 缺爱型 vs 独立型
- 不同女主与主角的关系起点不同（青梅竹马/偶然相遇/利益交换）
- 每个女主有自己的故事线，不只是主角的附属品

**稳定人设 + 固定流程 = 稳定期待**

- 爱吃醋的女主 + 其他女主偷家 = 读者永远爱看的场景
- 框架固定但内容不同，读者预料到了也乐此不疲
- 这套流程可以反复使用而不腻
- 关键：每次的具体内容要不一样

### 狗粮文的循环套路

**不能模仿升级文的突破模式**

- 牵手、接吻、上床是一次性的——写了一次，第二次就没感觉
- 升级文可以反复"突破筑基->装逼->突破金丹->装逼"
- 恋爱文不能"牵手曝光->装逼->接吻曝光->装逼"——越往后越别扭

**正确的循环方式**

- 学习短视频的固定流程重复拍模式
- 每期送来的"狗"不一样（不同的情境和触发条件）
- 稳定的人设组合 + 变化的情境 = 无限可用的套路

**感情升温的方法**

- 不依赖身体接触的升级
- 而是通过共同的困境、互相的理解、意外的发现来升温
- 每次升温都要有触发事件

### 事业线与爱情线的平衡

- 互相促进：事业线为爱情线提供场景和冲突，爱情线为事业线增加情感投入和牵挂，最好的状态是两条线交织推进
- 天花板：如果想要成绩的天花板突破，最终归宿是以事业线为主干，感情线为辅料。只有爱情线没有事业线，天花板会低很多。但纯事业线也可能因为缺乏情感投入而枯燥

### 主线认知：主线是一件事，不是升级

- 升级只是主角达成目标的行为，不是主线本身
- 《斗破苍穹》主线是"被退婚羞辱→上云岚宗复仇"，修炼是实现目标的行动
- 目标和行动要分开：目标是发财，行动可以是抢银行/打工/创业
- 把升级当主线会导致认知偏差，越写越歪
- 真正的主线更像是一件事：一个核心事件贯穿全文
- 《电子女友》主线是"治疗癌症"，不是感情推进——感情是行动
- 《全职高手》主线是"被辞退后重回巅峰"，不是升级
- 大主线写完后，要么通过铺垫开启第二条大主线，要么完结

**飞卢型高噱头主线**

- 不是以升级为主线的书：开局就是一个事件
- 如《过安检滴滴响，我满身枪伤被曝光了》——主线是身份曝光引发的社会反应
- 这类书的核心观感必须贯穿始终，不能中途偏移

### 感情线推进技巧

**感情线的本质：关系拉扯**

- 推进和拉开交替进行，不能只拉近不扯开
- 一直拉近关系→必须推→推了后面没得写→提前消耗完
- 扯开关系不是分手，而是心有芥蒂/暂时冷静/误会阻碍

**英雄救美：最有效的推进手段**

- 男频最佳感情推进方式：男主在事业线上的行为无意间救了女主
- 不是刻意去追女主，而是做自己的事顺便完成了英雄救美
- 女主因此倒追男主，避免"白给"观感
- 不同女主面临不同困境→不同的英雄救美→不同的爱上过程

**误会：制造拉扯的绝佳方法**

- 误会的本质：我以为事情是这样的，但实际上不是
- 感情线用误会：制造两人之间的隔阂，延缓关系推进
- 装逼打脸也用误会：《都市修仙》主角谦虚→对方以为他真弱→打脸更爽
- 经典案例：骨王的"我以为我很弱"、平平无奇大师兄的"以为师兄是天才"

**窗户纸事件：阶段跨越的关键**

- 好感度改变→关系阶段变化→爱情线阶段变化
- 设计一个"窗户纸"事件，一方好感度猛然提升
- 事业线为主：放在一级结构的小高潮上
- 爱情线为主：放在某一卷的大高潮上

### 爱情线四阶段实操

**四阶段概述**

- 阶段一：萍水相逢——展示外貌、性格、他人评价、爱好习惯
- 阶段二：怦然心动——产生好感，注意对方的存在
- 阶段三：暧昧升温——互动增多，关系微妙变化
- 阶段四：确认关系——突破窗户纸，正式确立

**填充爱情线的方法**

- 爱情线更多顺推而非逆推，不像事业线可以从高潮倒推
- 每个阶段内有多个节点，结合一级结构模板设计情节
- 填充故事不需要每个都奔着下一阶段推进
- 只要符合两人当前关系阶段，落在节点范围内即可

**不同阶段的过渡**

- 好感度→关系阶段→爱情线阶段，三者联动
- 过渡时设计"窗户纸"事件，在高潮中完成阶段跨越
- 了解女主过往经历属于爱情线的补充丰富，不等于阶段推进

### 男频感情线特殊规则

- 男频不写拉扯式恋爱：女频感情线是分分合合、制造糖和刀，男频不能写男主追女人、为女人付出——读者会骂。男频感情线本质是推女：从陌生→认识→熟知→单独约会→牵手→接吻→发生关系，功利、直白，递进关系清晰
- 现代读者的心态变化：现在男生普遍希望爱情里由女性来付出（类似女频霸总文的逻辑），不能再写男主追女人的情节。正确逻辑：男主追求事业→过程中无意间达成英雄救美→女主倒追。女主因为男主的行为而喜欢他，不是男主刻意讨好
- 女主倒追 vs 白给：白给是女主一接触就无理由爱上男主，不管条件差距；倒追是男主之前在事业线上的行为让女主产生好感，情绪逻辑成立。区别在于是否有说服力的铺垫
- 读者看感情线的真正目的：收获现实中缺失的异性情绪价值补偿。有女友/已婚的人也会看后宫文，因为现实缺乏情绪价值。CP行为、关系突破后的态度转变、展示给主角区别于他人的另一面——本质都是给予情绪价值。人设重要：某种人设里就有读者幻想的完美伴侣

### 后宫与炒股的写法区别

- 结构上的共性：后宫和炒股在中间写法上基本一致，都是男主和多个女主逐个进入暧昧阶段，但不确认关系，直到结局才确认关系（后宫全收/炒股多选一）
- 后宫写法的注意事项：不能和一个女主确认关系后再攻略下一个——会显得渣男；先确认的女主和后确认的女主身份失衡，后者有"小三"嫌疑；现代都市背景默认炒股（一夫一妻），古代/玄幻可放开；大结局时一次性全部确认关系，或大结局前集体确认
- 后宫修罗场的三种处理：
  1. 一笔带过：《斗破苍穹》式——两个女人互相看不惯，最多嘲讽两句，克制处理
  2. 关联回事业线：女主们争风吃醋→比谁对男主事业贡献更大→给事业线带来助力（最推荐）
  3. 被害人设：给女主塑造"每次忙事业就被偷家"的被迫害梗，形成固定笑点
- 炒股文的结尾：女主纷纷表白→男主多选一。建议开放性结局：不管选哪个都会被骂，不如不选

### 事业线为主文中的爱情线处理（提纯思路）

**九一开原则**

- 事业线为主的文，爱情线最多占一成
- 爱情线的每个情节都必须为事业线服务
- 三个条件满足其一才能写爱情线情节：
  - 爱情线为事业线带来帮助或阻碍
  - 可攻略对象是事业线的助力或完成奖励
  - 可攻略对象的人际关系为事业线带来帮助或阻碍

**核心观感必须一致**

- 同一个金手指也可以产生不同观感
- 如"无咏唱魔法"可以是降维打击观感，也可以是练功发疯观感
- 观感偏移 = 核心梗偏移 = 读者流失
- 所有故事必须夹在核心梗相关的期待点与爽点之间

**事业线中插入爱情线的方法**

- 女主自身有事业天赋，男主通过金手指参与其中
- 女主的家庭背景与男主事业线挂钩（如女主父亲是影视公司CEO）
- 按舞台剧目写法：往舞台里塞女主事业线相关内容，男主自然参与

### 创作大纲范式

**三步走：大纲→细纲→章纲**

- 大纲：敲定时间节点，按时间线罗列关键事件
- 细纲：按时间线细化，标注具体日期和事件
- 章纲：码字前根据细纲写具体章节内容规划

**大纲设计要点**

- 不要一开始就规划全书，先敲定一个时间节点
- 大纲以事业线为主导，但让女主与事业线产生强联系
- 好感度质变的大事件不要放在大纲层面，放在细纲和章纲
- 日常文好感度应该是小事件串联的缓慢增长，不要猛增

**女主与事业线的绑定**

- 每个女主自身及背后的家庭都和事业线串联→日常与事业互相糅合

### 狗粮文/感情线实操要点

- 感情线不要从暧昧后期开始：香吻奖励、穿男主衬衫等属于暧昧后期阶段。开头要写：如何认识→为什么产生情愫→接触的变化→人设碰撞。涩涩只是表现，不是重点，重心放感情线设计
- 情感转变的细节才是糖：女主大大咧咧→喜欢上男主后变得小女儿作态→这种转变才是狗粮。前后对比：符合人设但因爱做出微小改变→读者满足。不是直接写"她对他好"，而是写因爱而生的行为变化
- CP含蓄表达的东方美学：眼神交织、表情特写、环境氛围烘托比直接描写更有效果。"眼神都在拉丝"——用笔力把这种拉丝感表达出来。分步骤循序渐进：心理变化→肢体接触（从牵手开始）→暧昧感。情报密度控制：一个有趣的转折场景胜过千字心理描写
- 舞台写法：把有趣的场景当舞台：烟火大会、宿营、圣诞节、滑雪、烧烤。在舞台里营造氛围感+女主人设互动+亲密接触。新鲜的舞台 + 稳定的人设 + 变化的亲密接触 = 有效循环

### 配角与感情线的关系

- 所有配角的塑造必须有助于或阻碍事业线/爱情线发展
- 没有不可或缺的女配——只有女主才需要追求不可或缺的作用
- 情敌角色划进反派，必须被女主打倒
- 通俗小说有通俗小说的规则，不能让配角喧宾夺主

**后宫文读者的矛盾需求**

- 对男主道德洁癖高，不允许优柔寡断的感情伪君子
- 不能辜负任何一个女主的感情，应收尽收
- 不能和其中一个确认关系后继续暧昧（坐实出轨）
- 女主不是因为金钱地位爱上男主
- 女主是独立人格，不能纯依附男主
- 收后宫方式要合情合理，保留原汁原味人物性格
- 这六个条件不可能全部满足，必须取舍
