# 去AI写作门禁（6 Gate 细则）

_参考文件，按需加载_

> 门禁必读：写/续写章节后门禁阶段加载。包含 AI 写作指纹、核心规则、6 Gate、质量维度、文本健康检测、7 种 AI 模式检测。

---

## 校准原则（管所有规则的规则）

- **瞄准人类区间，不是 AI 的反面。** 人类写作的各项指标都在中间：偶尔一个路标词、偶尔一次排比、偶尔一段等长。把每条痕迹都反着来（零连接词、每段长短都不同、每句都有个性）是另一种指纹。
- **选，不叠。** 每章选 3-5 个最要紧的问题动手，其余留着。修完的文本要比原文更像人，不是更像「去过 AI 味」。
- **留余地。** 允许平淡的句子、没展开的想法、普通的段落。不把每个表面都打磨过。
- **密度判定。** 「清零 / 不超过 N」是识别强度，不是删除配额。单次出现且读感自然的不算问题，成簇、连段、明显在替读者宣布结论时才修。

## 误判白名单（不算 AI 证据，不修）

- 干净的语法和标点：人也这样写，故意加错是可识别的把戏。
- 单次或符合语境出现的某词、破折号、分号：一次或语境自然的不算，成簇套壳才算。
- 逐字引文、对话、引用的文件措辞里的任何表达。
- 作者样本里核实过的习惯：作者自己就爱用某词，留着。
- 正式的场合的正式语体：匹配场合比硬装随意更像人。
- 普通的中等句子和普通的段落。

## 修饰语原则

- 删**不加信息只加音量**的装饰：空挂在动词前后的程度/评价修饰（显得格外、更加、深刻地、有效地），删掉后句子意思几乎不变。
- 留**真改变信息**的：时间、频率、范围、否定、推测、程度（已经、仍然、偶尔、仅、至少、几乎、可能、未必），以及有具体结果的补语（跑得气喘吁吁、摔得门框发响）。
- **自检只问一句**：这个成分是在提供信息，还是在替读者加音量？前者留下，后者删掉或落回事实。
- 对话、引语、正式语体、作者原有习惯里的修饰语不强行清零。

## 篇章层检查（改写/审阅默认做，比词句层更有效）

1. **大纲测试**：把每段第一句抽出来连读。连成一份干净摘要就是提纲扩写的形状；人写的首句连读有跳跃和断口。修法是改变信息进入段落的方式，不是换首句。
2. **每段回答什么问题**：逐段写下隐含的问题。「发生了什么 → 为什么 → 结果 → 意义」的线性序列、结尾段都在答「这意味着什么」，是机器序列。让一个问题先于铺垫出现，或用一段对比/质疑前文替换一段后果。
3. **中段**：AI 最容易在正文中段暴露。中间三分之一要有开头预测不到的东西，相邻段落质地要变。
4. **位置指纹**：段落等长、引语总在段尾、列举总是三项、过渡总是同一公式、强调均匀分布。这些比词语更能挺过改写。

## 写作时避免AI痕迹
网文写作中避免AI痕迹的实用指南。核心目标：让文字读起来像人写的。

---

## AI写作指纹（必须避免）

### 高频AI用词

> 词无定性，分布才是判据：单次出现且读感自然的不算问题，成簇、连段、明显在替读者宣布结论时才修（见「误判白名单」）。

以下为**高频倾向类目**（检测/润色时的参考方向，不是 0 容忍清单）：

| 类别 | 替代原则 |
|------|---------|
| 抽象升华词（命运、宿命、注定） | 用具体事件代替抽象概念 |
| 万能比喻（像潮水般、如闪电般、仿佛春风） | 要么不用比喻，要么用生活化的比喻 |

### 章末总结体

**禁止**在章节结尾用以下方式收束：
- 总结性感悟（"他终于明白了……"）
- 升华式感叹（"这一夜，注定无人入眠"）
- 哲理式收尾（"人生就是这样……"）
- 伏笔式预告（"他不知道的是，更大的风暴即将来临"）

**正确做法**：章尾用动作、对话或悬念收束，让情节本身制造余韵。

## 核心规则

### 规则 1：段落长短交替（不是越短越好）

段落允许 1-8 句，短中长交替才像人。**全章等厚（如 >80% 段落 ≤3 句）是另一种 AI 指纹**——机器生成的文本长度分布均匀，人类写作短段、中段、厚段混用。

```
错：全章都是两三句一段，长度均匀（机械分布）

对：他盯着窗外。雨下了很久。      ← 短段
"你还在想她？"老刘问。
他没说话。                      ← 短段

他想起老刘刚才说的那句话，想起灶台上凉了半天的粥，想起自己出门时忘了关的灯——这些念头挤在一起，乱糟糟的，他一个都抓不住，最后只剩下一个：她不会再回来了。  ← 厚段（允许）
```

> 厚段（5-8 句）用于信息密集/情绪堆积；短段（1-2 句）用于停顿/转折/紧张。全章全是厚段同样不对。

### 规则 2：动作 + 对话 + 情绪反应

三要素循环推进，不要单写心理活动超过 2 段：

```
动作 → 对话 → 情绪反应 → 动作 → 对话 → ……
```

情绪不用"他感到/他觉得"，用身体反应和行为表现：
- 不写"他很紧张" → 写"手心全是汗，筷子差点掉了"
- 不写"她很愤怒" → 写"她把杯子摔在地上，碎片弹到脚背上也没弯腰捡"
- 不写"他很伤心" → 写"他在车里坐了二十分钟才发动引擎"

### 规则 3：短句优先（参考档，不是硬配额）

| 场景 | 句长 | 示例 |
|------|------|------|
| 打斗/紧张 | 3-8 字 | 他侧身。刀光一闪。血溅在墙上。 |
| 对话 | 口语化 | "你疯了？""可能吧。" |
| 日常 | 8-15 字 | 厨房里有炒菜的声音，闻着像辣椒炒肉。 |
| 描写 | 不超过 20 字 | 天快黑了，巷子里没什么人。 |

> 上表是「短句优先」的参考档。**允许穿插 30-50 字长句和 4-8 字碎片**，句长有波动才像人；全章句长高度均匀（90% 句子都在 10-25 字）才是问题（见 Gate 4）。

### 规则 4：口语化表达

- 允许用俚语、粗话（符合角色身份）
- 对话不要书面语（"我认为此事不妥" → "我觉得不靠谱"）
- 叙述也不要端着（"他目光如炬" → "他眼珠子一动不动盯着"）
- 短语优先于成语（"无可奈何" → "没办法"）

## 连续复用禁令

**规则**：不要连续使用原文中任何 12 字以上的原句。

写作时如果参考了素材/原文：
- 可以借用意思，但必须用完全不同的句式重新表达
- 连续 12 个字与原文相同即为抄袭式复用
- 替换同义词不算改写（"他快速地跑" → "他迅速地跑" 仍然违规）

**正确改写方式**：
```
原文：他一拳打在墙上，指节渗出血来，但他浑然不觉疼痛。
改写：拳头砸上墙的时候他没感觉。低头才看见血从指缝里往下淌。
```

## Show Don't Tell 原则

| Tell（告诉） | Show（展示） |
|-------------|-------------|
| 他是个胆小的人 | 他把检查报告在手里翻来覆去看了三遍，还是不敢打开 |
| 这间酒吧很吵 | 酒保凑到他耳边喊了两次他才听见 |
| 她很富有 | 她随手把一张信用卡丢在桌上，卡面上的数字比这顿饭贵十倍 |
| 两人关系很差 | 他把烟掐灭在她刚泡的茶杯里，她面无表情地把杯子推到一边 |
| 他很聪明 | 三秒钟。他看了三秒钟就把文件合上了。"第三页，第二行。" |

**核心方法**：
1. 用行为代替形容词
2. 用细节代替总结
3. 用对话代替旁白说明
4. 用反应代替情绪词

## 6 Gate 写作质量门禁（写章节必过）

> 本章节是 SKILL.md 中「写作质量门禁（6 Gate）」的**规则唯一源头**。
> 每章写完后按 Gate 1→6 顺序逐项自检，任一 Gate 不通过则打回重写对应片段。
> 门禁结果输出格式：`✅ Gate 1-6 写作质量：通过（禁用词0 / AI句式1处已修正）`，不通过则标注具体违规位置。

### Gate 1 文本健康（替代旧「禁用词」）

- 本地模式跑 `node scripts/scan-text-health.js < 正文.md`：口语虚词密度（净句警告）/ 断句呼吸（逗号链、长句占比）/ 修饰分布（比喻、封闭逻辑词）/ 认知句模式 / 标点硬伤
- 输出 🟡 提示按健康导向修，不是逐词禁用；❌ 硬伤（半角标点、引号不成对）必须改
- 认知句模式（他总觉得/这让他知道/久到/忽然）允许 1 处，成簇时替换为直接动作或引述

### Gate 2 AI 句式

- 章末总结/升华体：`他/她终于明白…` `这一刻，他才真正懂得…` 等 → 违规
- 论文体段落：先论点后论据的"总分总"结构 → 违规
- 三连排比癖：连续 3 个相同句式排比 → 违规
- 万能结论词：`其实` `毕竟` `无论如何` 强行总结 → 违规

### Gate 3 心理外化

- 连续 ≥ 3 句纯心理描写（无动作/对话穿插）→ 违规
- 心理活动必须外化：用动作、表情、对话、反应代替内心独白
- 内心独白单段不得超过 2 句，且前后必须有外部动作锚点

### Gate 4 节奏

- **段落等厚 → 违规**：全章 >80% 段落 ≤3 句（或全部厚段无短段），需短中长交替（1-8 句均允许，见规则 1）
- **长句密度过高 → 违规**：25 字+ 句子占比 >50%（偶尔连续长句是人类区间，密度才是 AI 指纹）
- **句长过于均匀 → 违规**：90% 句子都挤在 10-25 字区间，无 4-8 字碎片、无 35+ 字长句穿插
- 全文节奏单一（全快或全慢）→ 违规，需长短交替
- 打斗流水账（"你一拳我一脚"式）→ 违规

### Gate 5 对话

- 对话不推进剧情/不揭示性格 → 违规（凑字数对话）
- 对话书面腔（"汝""甚好""岂能"滥用）→ 违规
- 对话格式：中文正文一律使用**全角双引号“ ”**（不用「」、不用半角 "），全文统一 → 违规
- **正文排版细节**：每段首行缩进两个全角空格；正文不得混入半角标点（, . : ; ! ?）；省略号用「……」、破折号用「——」（不用 ... 或 -）→ 违规
- 连续 3 句无动作/神态标签的"站桩对话" → 违规

### Gate 6 结尾

- 章尾出现总结、升华、点题 → 违规
- 章尾无钩子（无悬念/反转/危机/新信息）→ 违规，需补章尾钩子
- 章尾强行留白但前文无铺垫 → 违规

## 质量维度检查

完成一章后，按以下 5 个维度自检：

### 1. 核心一致性（权重最高）
- 剧情是否与大纲/前文一致
- 人物行为是否符合人设
- 设定是否有前后矛盾

### 2. 表面改写（防AI指纹）
- 是否包含AI高频用词（见上表）
- 章尾是否有总结/升华
- 是否有大段纯心理描写
- 段落长度是否均匀（全章等厚，见 Gate 4）

### 3. 格式一致性
- 对话格式统一（中文用全角“ ”，不是「」/半角"）
- 正文标点全角、段首缩进两全角空格（见 Gate 5）
- 场景切换有明显标记
- 时间线清晰可追踪

### 4. 可读性
- 句长是否过于均匀（无短句碎片/无长句穿插）
- 25 字+ 长句占比是否 >50%
- 对话是否口语化
- 是否有未解释的生僻词/设定术语
- 节奏是否有快有慢（不能全是一种节奏）

### 5. 逻辑连贯性
- 角色动机是否合理
- 事件因果链是否清晰
- 时间线是否对得上
- 角色的知识范围是否合理（不能"开上帝视角"）

## AI 特征高压区与对策（检测器反馈驱动 2026-10-07）

> 外部 AI 检测器（朱雀等）实证：以下三类段落最容易判高 AI 特征，主动处理能显著降分（实测 AI 特征 66.8%→10.9%）。

**高压区 1：纯描写段（信息密度过高）**
- 症状：每句都提供新信息（碎石/槐树/泥土/树根/绕开/崖壁……），描写太高效
- 对策：**描写笨化**——插入无信息动作（滑倒龇牙、倒鞋石子、停下歇脚）、琐碎细节（石子灰的圆溜溜的）、跑题念头（明天柴火没处劈）；让行进变"笨"

**高压区 2：夜间独处 / 悬念段（意象连续铺陈）**
- 症状：神秘感连续推进，每个动作都指向结果，比喻密集
- 对策：**悬念打断**——插日常琐碎（起夜、野猫、尿壶、听风听狗）；比喻砍到 1 个以内

**高压区 3：比喻密集（"像/仿佛"成簇）**
- 症状：全章「像」>8 次，或一段 3 个比喻
- 对策：全章「像」≤5，只留最生活化的（拉风箱、羊粪蛋子）；其余换直接描写或删

**高压区 4：解释性对话（一段话塞多个信息点）**
- 症状：角色一段话交代 3 个信息点（异动/赶一夜/借剑），或「宗门一定会查…后会有期」式完整收尾
- 对策：**对话试探化**——信息拆散到多轮对话，中间插对方反应/环境；加停顿、吞字（「这剑要是从那儿出来的——」没说完）、口语客气改短句（「你再使一遍？」不是「你能再使一遍吗？」）

**高压区 5：意象收尾妙笔（AI 的「妙一笔」）**
- 症状：影子晃了晃**，又定住了**；话说完**，气氛凝固了**——AI 总想在场景收尾处加个精致意象
- 对策：**收尾删妙笔**——「影子晃了晃」就完了，人写到这里会停

**高压区 6：万能反应词**
- 症状：表情复杂/若有所思/欲言又止 作角色反应
- 对策：换具体动作（张了张嘴，到底没说话 / 步子比来时慢）或直接不写反应

**全局：开头信息密度打散**
- 症状：开头 3 句交代完天气+环境+动机（每句都干活）
- 对策：信息拆碎分段落，插入主观废话（这雨下得人心烦）、重复词（几丛。就几丛。）、口语纠正（不对，是两天两夜）、碎片短句（还没停。）

## 7 种 AI 写作模式检测

### 模式 1：AI 高频词
直接替换表：

| 禁用 | 替换为 |
|------|--------|
| 不禁 | 删掉 |
| 仿佛/宛如 | 删掉或用具体描写 |
| 映入眼帘 | 删掉 |
| 心中暗道 | 用动作展示思考 |
| 沉声道/淡淡地说 | 换成动作标签 |
| 脸色一变 | 用具体表情/动作 |
| 嘴角微扬 | 他笑了/他翘了下嘴 |
| 不由自主 | 删掉 |
| 只见/此时此刻 | 删掉 |
| 目光如炬 | 删掉或具体化 |

### 模式 2：弱化副词泛滥
阈值：每 1000 字超过 3 个 = AI 签名。
重点监控：微微、淡淡、缓缓、轻轻。

### 模式 3：意义膨胀
- "意义深远" → 写具体后果
- "前所未有" → 给出对比参照
- "可谓" → 删掉

### 模式 4：万能结论
- "未来可期" → 用未解决的紧张感结尾
- "前途无量" → 删
- "充满希望" → 写具体的下一步动作

### 模式 5：论文体段落结构
小说中出现以下开头句 = AI 入侵：
- "不难看出""由此可见""事实上""综上所述"

### 模式 6：书面语连词泛滥
叙事散文中频繁出现：
- "于是乎""与此同时""从而""因而""诚然"
→ 口语化替代或直接删除。

### 模式 7：三连排比癖
AI 喜欢把事情凑成三个以显"完整"。→ 砍到只剩最有力的一条。
