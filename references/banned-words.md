# AI味禁用词与句式表

> 分两档：**一级 = 真 AI 指纹，0 容忍**（出现即替换）；**二级 = 正常词汇，高频才违规**（单章 ≥3 次替换至少 2 处）。
> 判定依据：一级词是人正常写作几乎不用的模板化表达；二级词人也会写，AI 病态在密度不在出现。

## 一级禁用词（出现即替换，0 容忍）

### 表情类（AI 万能反应库）
眼中闪过、嘴角勾起、眉头微皱、眉眼低垂、瞳孔微缩

### 心理类（内心独白模板）
心中一动、心头一震、心下了然、心中暗道、心底泛起

### 判断类（书面判断腔）
不容置疑、不易察觉、显而易见、毫无疑问、不可否认

### 动作类（AI 万能停顿）
深吸一口气

### 情态类（比喻引导词）
仿佛、犹如、宛若

### 过渡类（AI 情绪外化高频）
不由自主、情不自禁

### 形容类（堆砌式）
闪烁着光芒

## 二级禁用词（高频出现时替换：单章 ≥3 次 → 违规）

> 这些词正常小说也会用（突然/微微/一丝/隐约…），**单次出现不违规**；AI 病态是反复堆叠，按密度判定。

### 情态类
好像、一丝、一抹、些许、几分、隐约

### 动作类
缓缓、不禁、微微、轻轻、淡淡

### 形容类
坚定、狡黠、深邃、凛冽

### 过渡类
突然、瞬间、忽然、自然而然

## 总结句式（0 容忍，章末出现即违规）
- "他/她终于明白..."
- "他/她这才意识到..."
- "此刻，他/她..."
- "一切...都..."
- "原来..."

## 排比句式（0 容忍）
- 连续3句以上相同结构的排比
- "有的...有的...有的..."
- "一边...一边...一边..."

## 升华句式（0 容忍）
- "这一刻..."
- "他知道..."
- "她明白..."
- "这就是..."

## 禁用句式模板

| 句式 | 示例 | 问题 |
|------|------|------|
| "...，带着..." | "他说，带着一丝无奈" | 万能状语 |
| "像XX一样" | "像刀子一样锋利" | 陈词滥调 |
| "他的声音很轻，却像..." | AI最爱声音描写 | 过于文艺 |
| "仿佛能...一般" | "仿佛能穿透一切一般" | 文言腔 |
| "XX说道" | "好的，他说道" | 机械标签 |
| "他/她感到..." | "她感到一丝失落" | 告诉而非展示 |
| "他/她意识到..." | "他意识到事情不对" | 直接告知 |
| "眼中闪过一丝XX" | "眼中闪过一丝悲伤" | 模板化 |
| "嘴角勾起一抹XX" | "嘴角勾起一抹冷笑" | 模板化 |
| "心中涌起一股XX" | "心中涌起一股暖流" | 模板化 |
| "他/她总觉得…" | "他总觉得有什么在盯着他" | 认知开头模板 |
| "这让他/她知道…" | "这让他知道自己还活着" | 认知总结模板 |
| "X了很久，久到…" | "看了很久，久到腿都麻了" | 强调重复结构 |

## 替换策略速查

| 原文类型 | 替换方法 | 示例 |
|----------|----------|------|
| 抽象情绪词 | 具体动作 | "紧张"→"手在抖" |
| "感到XX" | 外化表现 | "感到愤怒"→"攥紧拳头" |
| 形容词堆砌 | 白描手法 | "美丽动人的笑容"→"她笑了" |
| 书面表达 | 口语化 | "不容置疑"→"就是" |
| 解释性描写 | 留白 | "他因为害怕而..."→"他退后一步" |
| 连续排比 | 保留最强一条 | 3句排比留1句 |
| 总结升华句 | 直接删除 | "这一刻，她终于明白了..."→删 |
