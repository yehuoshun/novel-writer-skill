# 钩子技法大全

> 钩子核心技法：章尾钩子13式/章首钩子7式/实战模板/段落级钩子/悬念编排/钩子禁忌

## 钩子式 ↔ 追踪类映射

> SKILL.md「钩子追踪」表定义 11 项追踪类（章首 5 类 + 章尾 6 类，悬念钩章首/章尾共用，去重后 10 个唯一类，用于 `last_hook_start/last_hook_end.type` 记录与统计）。
> 写章节用下面的具体技法式，**记录时统一映射到追踪类词汇**，保证跨章统计口径一致。
> 一式可对应多个追踪类时，按本章实际效果选最贴切的一个。

### 章尾 13 式 → 章尾 6 类

| 13 式 | 追踪类 | 判定要点 |
|-------|--------|----------|
| 突然揭示 | 新信息钩 | 抛出改变全局的信息 |
| 紧急危机 | 危机钩 | 章尾陷入危险 |
| 未完成动作 | 悬念钩 | 动作被打断，留待下章 |
| 身份反转 | 反转钩 | 身份/关系突然反转 |
| 两难抉择 | 决策钩 | 重大选择摆到面前 |
| 神秘物品/线索 | 悬念钩 | 抛出未解之谜（偏物） |
| 倒计时 | 危机钩 | 时间压迫逼近 |
| 承诺/威胁 | 悬念钩 | 未兑现的承诺/威胁悬置 |
| 离奇消失 | 悬念钩 | 人或物消失留谜 |
| 隐藏含义 | 新信息钩 | 表面话下有深层含义 |
| 意象钩子 | 悬念钩 | 用意象暗示未解之事 |
| 回声钩子 | 悬念钩 | 呼应前文线索制造回响 |

## 章尾钩子 13 式

### 1. 突然揭示
抛出改变全局的信息。
- "信上的日期，是他死后第七天。"
- "打开保险柜，里面只有一张照片——照片上的人，是她自己。"

### 2. 紧急危机
下章必须回应的紧迫威胁。
- "裂缝在扩大，灵石还差三块。"
- "倒计时显示还剩 180 秒，但红线还没找到。"

### 3. 未完成动作
动作被新变量打断。
- "他刚伸手——'别动。'身后传来一个声音。"
- "门推开一半，一只手从里面伸出来，把门关上了。"

### 4. 身份反转
某人不是我们认为的那个人。
- "他摘下口罩。那张脸，和魔王一模一样。"
- "她说她叫林小月。但档案上写的是：林小月，已故。"

### 5. 两难抉择
被迫在两个坏选项中选一个。
- "救生艇只能坐两个人，水里有三个。"
- "签了这份文件，公司保住了，但他得进去。"

### 6. 神秘物品/线索
重要但含义未知的物件。
- "一张昨天拍的照片，拍摄角度——是从她窗外拍的。"
- "包裹里是一把钥匙，附了张纸条：'你欠我的。'"

### 7. 倒计时
时间不够用。
- "炸弹上的数字在跳：02:57。"
- "医生说还有三个月。那是两个月前的事了。"

### 8. 承诺/威胁
有人宣布了行动意图。
- "今晚十二点之前，我会告诉所有人你做了什么。"
- "明天，整个公司都会知道这个秘密。"

### 9. 离奇消失
不可能的消失。
- "手铐还在，人没了。整个房间只有一个门，门没开过。"
- "监控里她走进电梯，但下一层的摄像头没有拍到她出来。"

### 10. 隐藏含义
表面正常的对话，实际暗藏信息。
- "他说：'你和妹妹真像。'——她是独生女。"
- "她在遗嘱里把房子留给了'家里的老朋友'。她养了一只猫。"

### 11. 意象钩子
反复出现的意象在章尾发生变化，暗示转折。
- "窗台上那盆枯了一个月的茉莉，突然冒出了花苞。"
- "灯又灭了。但这次，她闻到了烟味。"

### 12. 回声钩子
章尾句子呼应开头，关键细节变了。
- 开头："她说她永远不会原谅他。"
- 结尾："她说她永远不会原谅他。但她的手，攥得更紧了。"

### 13. 留白钩子
故意不揭示发生了什么，只展示反应。
- "他看了信。脸色变了。什么也没说，把信叠好放进口袋。"
- "电话那头沉默了很久。然后她说：'我知道了。'挂了。"

## 章首钩子 7 式

### 1. 悬念对话开局
直接从一段意味深长的对话开始。
- "你确定要这么做？/ 确定。/ 那你就别后悔。"

### 2. 闪前碎片
先给一个结果碎片，再回到正常叙事。
- "后来他才知道，那个电话改变了所有事。但此刻他还一无所知。"

### 3. 倒计时开局
开头就建立紧迫感。
- "距离合同到期还有 72 小时。"

### 4. 神秘独白
第一人称的诡异内心独白。
- "我一直在想，那天如果我没有回头，一切会不会不一样。"

### 5. 反差场景
两个截然不同的场景并列。
- "一边是婚礼现场，香槟塔堆得老高。另一边，医院走廊的灯在闪。"

### 6. 未完成动作开局
动作进行中被截断。
- "他刚把钥匙插进锁孔——"

### 7. 意象预示
用环境意象暗示即将发生的事。
- "天边烧得通红，像是什么东西在着。她抬头看了一眼，继续走。"

## 实战章末钩子模板

### 一、系统激活型钩子

**真实范例**：
> 就在他万念俱灰之际。一个冰冷的机械音，突然在他脑海中响起。叮！【年少轻狂系统，正式启动。】

**结构**：绝望时刻 → 突然声响 → 系统名称

**模板**：
```
就在{主角}{最低谷状态}之际。
{一个感官描写}。
叮！
【{系统名}，正式启动。】
```

**变体**：
- 就在他准备放弃的时候，眼前突然浮现出一行金色大字。
- 脑海中忽然响起一道机械音。
- 手背上浮现出一个奇异的纹路。

---

### 二、悬念预知型钩子

**真实范例**：
> 我冷眼看着笑得前仰后合的人。笑吧。多笑会儿。过了今天，你们就再也笑不出来了。

**结构**：对方嚣张 → 主角冷观 → 预告反转

**模板**：
```
{主角}{冷静/冷漠地}看着{对方的嚣张行为}。
{一个短句：继续吧/慢慢来/不着急}。
{预告即将发生的反转，不透露细节}。
```

**变体**：
- 他不知道的是，真正的灾难还在路上。
- 但所有人都忽略了一个细节。
- 可她不知道，那个决定，将彻底改变一切。

---

### 三、截断型钩子

**真实范例**：
> 仅仅一口！她的瞳孔猛地收缩成针尖状。轰！一股恐怖到难以形容的热流，瞬间在她的腹中炸开！这......这不是普通的粥！这是什么？

**结构**：小动作 → 巨大反应 → 疑问（不回答）

**模板**：
```
{一个小动作}。
{剧烈反应}。
{震惊/疑问——本章结束，不给答案}。
```

**变体**：
- 她打开门——床上躺着的那个男人，让她的血液瞬间凝固。
- 系统面板上跳出一行字，他看清后，整个人都愣住了。
- 电话那头沉默了三秒，然后说出了一个他做梦都没想到的名字。

---

### 四、选择型钩子

**真实范例**：
> 【选择一：无敌一百年！】奖励：勾玉轮回眼、查克拉果实……代价：无敌百年后即刻暴毙。
> 【选择二：永生者】奖励：永恒不死！代价：实力永久卡在超影级。

**结构**：两个/多个选项 + 各自利弊 → 章节结束

**模板**：
```
【选择一：{诱人选项}】
奖励：{极其诱人的奖励}
代价：{隐含风险}
【选择二：{另一个选项}】
奖励：{另一种诱人奖励}
代价：{另一种风险}
```

**变体**：
- 眼前出现两条路：一条通往光明，一条通往深渊。
- "你只有一次机会。"他看着面前的两个按钮。

---

### 五、危机升级型钩子

**真实范例**：
> "都给老子出来！快点！"哐啷！！！一只沾满泥污的军靴，粗暴地踹开了笼门。

**结构**：突然声响 → 新威胁出现

**模板**：
```
{突然的声响/动作}！
{新威胁出现}。
{主角的恐惧/紧迫反应}。
```

**变体**：
- 走廊尽头传来脚步声。越来越近。
- 手机屏幕突然亮了。一条来自未知号码的消息。
- 门把手在转动。

---

### 六、身份即将揭露型钩子

**真实范例**：
> 一个富商盯着我，迟疑的开口："沈大姑娘可曾去过西域？""我在那边经商，听说西域那边有个女人，跟皇室有些瓜葛，也叫沈什么月。"

**结构**：旁人发现线索 → 主角紧张 → 暂时被打断

**模板**：
```
{一个旁观者}突然{提出疑问/发现线索}。
"{暗示主角真实身份的话}"
{其他人不以为意，主角暗暗紧张}。
```

---

### 七、情感转折型钩子

**真实范例**：
> 就在这时，江亦瑶的表情突然变了，眼眶一红，两行清泪毫无征兆地滚落下来。她带着哭腔："求你了，苏牧，让我走吧……"

**结构**：情绪突变 → 意想不到的示弱 → 主角动摇

**模板**：
```
就在这时，{角色}的{表情/态度}突然{大变}。
{一个出人意料的示弱/请求动作}。
"{戳中主角软肋的话}"
```

---

### 八、信息差型钩子

**真实范例**：
> 花有重开日，人无再少年。自己怎么就把日子，过成了这副狗屎样？

**结构**：主角自嘲/感慨 → 读者知道主角即将迎来转机 → 章末反转

**模板**：
```
{主角的自我怀疑/感慨}。
{一个意象/比喻}。
{暗示即将改变，但不明说}。
```

---

### 九、对话悬念型钩子

**真实范例**：
> "我有一个请求。"苏牧缓缓说道。
> "你说。"
> "离婚之前，我要证明一次自己。"

**结构**：提出请求 → 对方答应 → 说出意想不到的话

**模板**：
```
"{提出请求的前半句}"
"{对方回应}"
"{意想不到的后半句——不是读者预期的}"
```

---

### 十、时间跳跃型钩子

**真实范例**：
> 三分三秒后。江亦瑶神色从容地走出房间，整理了一下微乱的衣服。

**结构**：时间标记 → 结果展示 → 留白中间过程

**模板**：
```
{精确/模糊的时间标记}。
{出人意料的结果}。
{暗示过程的一句话}。
```

### 章节钩子选择指南

| 故事阶段 | 推荐钩子类型 | 频率 |
|----------|-------------|------|
| 第1章 | 系统激活/截断/危机升级 | 必须强 |
| 2-3章 | 选择/信息差/情感转折 | 强 |
| 中期日常 | 对话悬念/信息差/身份即将揭露 | 中 |
| 高潮前 | 危机升级/悬念预知 | 强 |
| 大结局 | 时间跳跃/情感转折 | 收束 |

### 章末钩子三种实战写法

### 收获预告型

```
{当前行动接近完成}。
{暗示即将获得的奖励}。
{一句话暗示奖励比预期更大}。
```

效果：读者期待下一章的收获兑现。适用于副本/任务接近尾声。

### 反派逼近型

```
{主角当前状态}。
{暗处/远方，反派的某个行动}。
{暗示这个行动将影响主角}。
```

效果：读者为主角的安全担忧，急于看到冲突。适用于铺垫段结尾。

### 行动预告型

```
{主角做出一个决定}。
{一个准备动作}。
{暗示即将发生的行动}——不写结果。
```

效果：读者期待主角的行动过程和结果。适用于即将装逼/打脸前的章末。

### 操作要点

- 每章结尾多花100字放钩子，完读率显著提升
- 钩子不需要复杂，点到即止
- 关系网越丰富，钩子的选择越多（可以用敌人的敌人、旧角色回归等做钩子）

### 悬念构建核心法则

### 悬念的本质

当读者的心理预期有两个及以上不同的走向时，剧情就有了悬念——因为他觉得都有可能。

### 悬念 vs 伏笔

| 维度 | 悬念 | 伏笔 |
|------|------|------|
| 目的 | 让读者猜测接下来会怎样 | 为后面的揭示埋下前期线索 |
| 位置 | 通常在章节/段落结尾 | 通常在叙事中自然带出 |
| 揭示时机 | 短期内揭晓 | 长期后才揭示 |
| 情绪效果 | 紧张/好奇/期待 | 震惊/恍然大悟 |

### 四种悬念信息顺序模板

| 类型 | 结构 | 适用 |
|------|------|------|
| 直白剧情 | 提出疑问→公布答案 | 基础叙事 |
| 探索剧情 | 提出疑问→正常提示→公布答案 | 铺垫段 |
| 意外剧情 | 提出疑问→虚假提示→公布答案 | 反转段 |
| 意外+反转 | 提出疑问→虚假提示1→虚假对立提示2→公布答案 | 高潮段 |

### 触发型钩子（分层钩子）

在一段完整的剧情中，用多个层次制造递进悬念：

```
第1层：展示初步成果 → 观众初步反应
第2层：揭示这还不是最终结果 → 观众期待升级
第3层：展示超出预期的元素 → 观众震惊
第4层：主角还能进一步提升 → 留下钩子，开启下一段
```

**关键**：每一层都要有角色的反应来验证悬念的力度

## 短篇/段落级钩子类型

短篇没有「黄金三章」，靠的是每个段落的钩子。拆文时重点看每一处转折用了什么钩子、钩子强度如何、读者会不会被勾住。

---

### 1. 信息差钩子（Information Gap）

**定义**：读者知道某个关键信息，但角色不知道。读者替角色着急、替角色害怕。

**什么时候用**：
- 铺垫段，建立读者优越感
- 反转前的最后一层压制
- 让读者猜「他什么时候才会发现」

**示例**：
> 他笑着接过咖啡，不知道她刚才在里面加了一片安眠药。

**有效性**：★★★★★
- 短篇最常用的钩子
- 零成本制造紧张感
- 重生文、复仇文的核心驱动力
- 注意：信息差不能拖太久，超过 3000 字读者会烦

---

### 2. 倒计时钩子（Countdown）

**定义**：设置明确的时间压力。某个节点到了、某件事就要发生。

**什么时候用**：
- 发展段，推进节奏
- 高潮前收紧张力
- 短篇中段防止节奏塌陷

**示例**：
> 离婚冷静期还剩最后三天。三天后，他签不签都无所谓了。

**有效性**：★★★★☆
- 制造紧迫感最直接
- 适合婚恋、世情、悬疑题材
- 倒计时可以是具体时间，也可以是事件节点（「等他回来」「孩子出生前」）
- 注意：倒计时一旦设定，必须到期兑现，不能烂尾

---

### 3. 反转钩子（Reversal）

**定义**：读者的预期突然被打破。以为是 A，结果是 B。

**什么时候用**：
- 全篇核心位置（60-75%）
- 章节结尾，迫使读者翻下一章
- 结构的关键转折点

**示例**：
> 她打开遗嘱，上面写的不是她的名字。
> 是她母亲的。

**有效性**：★★★★★
- 短篇的灵魂钩子
- 好的反转钩子让读者必须重读前文
- 注意：反转必须有铺垫，无铺垫的反转是作弊
- 拆文时重点看：铺垫了几条线索？误导方向是什么？

---

### 4. 暗牌钩子（Hidden Card）

**定义**：主角藏了一张牌没打出来，读者知道她有这张牌，但不知道什么时候打、打出来有多大的威力。

**什么时候用**：
- 铺垫段的结尾，给读者期待
- 反转前的蓄力期
- 和信息差钩子配合：读者知道暗牌、对手不知道

**示例**：
> 婆婆骂了整整十分钟。我一句话没说。
> 手机录音还在跑。

**有效性**：★★★★☆
- 期待感强，读者等着看「亮牌」
- 适合世情、婚恋、职场题材
- 暗牌必须兑现，兑现时威力要配得上等待
- 注意：暗牌不能藏太久，短篇里最多藏 30% 篇幅

---

### 5. 打脸钩子（Face-slap）

**定义**：某个角色正在得意/嚣张/嘲笑主角，但读者知道他马上就要被打脸。

**什么时候用**：
- 情绪需要快速拉升时
- 反转之后的高潮释放
- 配合暗牌钩子一起使用

**示例**：
> 【就你？也想跟我争？】她笑得前仰后合。
> 我没说话。只是把那份亲子鉴定报告从包里拿了出来。

**有效性**：★★★★★
- 情绪爽感最高
- 打脸前的嚣张越狠，打脸时越爽
- 适合所有题材
- 注意：打脸要干脆利落，不能拖。一句话打脸比一段话打脸爽

---

### 6. 代价钩子（Cost）

**定义**：暗示主角即将失去某样东西，或某个选择要付出惨重代价。读者替主角揪心。

**什么时候用**：
- 发展段，加重情感投入
- 反转前，让读者以为主角要输了
- BE 结尾的铺垫

**示例**：
> 我知道举报他意味着什么。举报了他，我也完了。
> 但我还是按下了发送键。

**有效性**：★★★★☆
- 制造共情最有效
- 读者会代入「如果是我怎么办」
- 适合世情、死人文学、治愈向
- 注意：代价必须真实。如果主角最后什么都没失去，代价钩子就失效了

---

### 7. 弱者/孩子钩子（Vulnerable）

**定义**：引入一个需要被保护的弱者（孩子、老人、病人、动物），读者的保护欲被激发。

**什么时候用**：
- 开头，快速建立共情
- 中段，给主角一个不得不行动的理由
- 制造额外情感张力

**示例**：
> 女儿躲在门后面，捂着耳朵。
> 她才四岁，什么都不懂。
> 但她知道不该出声。

**有效性**：★★★★☆
- 共情速度最快
- 一个弱者角色可以让整个冲突的分量翻倍
- 适合婚恋、世情、追妻
- 注意：弱者不能只是工具人，要有自己的行动线（哪怕很小）

---

### 钩子组合

短篇不是用一个钩子，而是组合使用：

| 组合 | 效果 | 适合题材 |
|------|------|----------|
| 信息差 + 暗牌 | 读者知道主角在憋大招 | 复仇、世情 |
| 倒计时 + 代价 | 时间紧迫 + 选什么都亏 | 悬疑、婚恋 |
| 反转 + 打脸 | 情绪过山车 | 所有爽向短篇 |
| 弱者 + 代价 | 共情拉满 | 追妻、世情、死人文学 |
| 暗牌 + 打脸 | 爽感最强 | 复仇、逆袭 |

### 拆文检查清单

拆文时对每个钩子评估：

1. 钩子类型是什么？
2. 钩子在第几句话/第几个字出现？
3. 钩子强度（1-10）？
4. 钩子是否在合理位置兑现？
5. 铺垫和兑现之间的距离是否合适？
6. 是否有钩子未兑现（烂尾）？

---

### 实战钩子示例

1. **反常事实**：'他死过一次，这是他第二次参加自己的葬礼。'
2. **关系背叛**：'她最好的朋友嫁给了她的前夫，而她是最后一个知道的。'
3. **时间压力**：'距离截止还有两小时，但她刚刚发现方案里的数据全是假的。'
4. **隐藏底牌**：主角知道什么，但对手/读者暂时不知道
5. **即将打脸**：反派正在得意，读者知道主角马上要翻盘但还没掀牌
6. **善意陷阱**：看似关心实则伤害，'为你好'式操控

### 新增钩子类型

### 8. 灵魂旁观钩子（Ghost POV）

**定义**：主角已死，以灵魂飘在半空的视角叙述。全知但无力改变。

**示例**：
> 我的魂魄慢慢飘起来，看着妈妈铁青的脸。
> 对不起妈妈，我没能站直。

**有效性**：★★★★★
- 第一句就告诉你主角死了——这是最强的信息炸弹
- 天然制造信息差：灵魂能看到所有人的真面目
- 拆文时注意：灵魂视角的叙述限制（只能看不能动）是否被严格遵守

### 9. 异常物件钩子（Anomalous Object）

**定义**：一个不该出现在这里的物件引发全局。

**示例**：
> 避孕套日期突然变了，连味道也变成了我以前过敏的芒果味。
> 我笑着点头。

**有效性**：★★★★★
- 极强代入感——每个人都会遇到日常异常
- 物件本身承载信息量极大（品牌变化=有人来过）
- "笑着点头"四个字制造悬念——主角发现了什么？她会怎么做？

### 10. 假意顺从钩子（Feigned Compliance）

**定义**：重生后主角主动给出前世拼命保护的东西。读者知道原因，对手以为她疯了。

**示例**：
> "你既然想要，就都给你吧。"
> 反正谁拿到这笔巨额遗产谁就大祸临头，正愁保命的方法呢。

**有效性**：★★★★☆
- 双重信息差：对手以为主角傻了，读者知道她在下套
- 读者不知道具体是什么套——三重悬念

### 11. 冷发现钩子（Cold Discovery）

**定义**：发现异常后第一反应不是崩溃而是极度冷静。冷静本身制造悬念。

**示例**：
> 钥匙扣上印着"悦安月子中心VIP"。我们明明没有孩子。
> 我笑着点头。当天就去月子中心记下了预约单。

**有效性**：★★★★★
- 越冷静越可怕——读者期待爆发
- 与传统"哭闹→崩溃"模式形成反差

### 新增钩子组合

| 组合 | 效果 | 真实范例 |
|------|------|----------|
| 异常物件 + 冷发现 | 日常悬疑感+智商碾压 | 《钥匙扣》：月子中心钥匙扣→笑着调查 |
| 灵魂旁观 + 弱者 | 极致悲剧+保护欲 | 《脊椎手术》：灵魂看被逼→"只是想听一句疼不疼" |
| 假意顺从 + 暗牌 | 三重信息差+爽感蓄力 | 《晚风遇见新晴》：给遗产→其实是陷阱 |
| 阶梯背叛 + 冷发现 | 层层加码+全程冷静 | 《避孕套》：出轨→挪用→害死妈妈 |

### 对话情绪五级递增

写矛盾冲突时，对话越不礼貌，情绪越强烈：

1. **客观陈述事实** — 最弱
2. **客观陈述 + 提出建议** — 礼貌但有力
3. **主观指责** — 开始有冲突感
4. **主观指责 + 强制命令** — 强情绪
5. **主观指责 + PUA抬升自己** — 最强

**最强话术：** 打着"为你好"的幌子，句句不离关心，但句句都是嫌弃、指责、厌恶

### 不公平伤害钩子

- 不公平伤害 = 不公平（主角无辜）+ 伤害（物理+精神）
- 精神上的伤害更能拉动读者情绪——大多数读者受气的时候多
- "不患寡而患不均"：减月例大家都减（公平），但唯独主角药材降了一等（不公平）
- 随便挑一种写到位都能拉起对反派的仇恨

### 围观者质量层级

震惊效果取决于围观者的层次：
1. 低质量：群演、打杂、实习生
2. 中质量：懂行的技术人员、副手
3. 高质量：行业大佬、领导

围观者根据以往经验对比主角表现，越细微的情绪变化和心态差异，读者越爽。

### 期待接力法

- 确保读者脑中有三个好奇的东西：两长一短
- 长期待收回后变短期爆发，同时新的长期待已铺好
- 短篇中：一个主悬念+一个副悬念，结尾同时引爆
