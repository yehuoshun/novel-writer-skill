# 人物设计与分析（四）

> 作者经验笔记（下）：男频恋爱文攻略/装逼打脸/移情与标签/高级爽点模板

## 男频恋爱文完整写作攻略

> 恋爱文的本质是满足情绪价值和自尊价值，核心技法是把恋爱当升级文写。

**读者为什么看恋爱文**：
- 情绪价值：填补"被需要、被在乎"的情感空缺→一个优秀女生欣赏自己喜欢自己
- 自尊价值：女主条件好→带出去有面子→配角羡慕嫉妒→自尊满足
- 男主本质是摄像头→读者代入的视角→女主对男主好=对读者好
- 高身份女主（总裁/女帝/宗主）的原因→更强的装逼打脸工具人+更大的自尊满足

**核心技法：把恋爱当升级文写**：
- 暧昧拉扯的过程才是最有吸引力的→在一起反而不无聊
- 关键在于制造各种内外部阻碍+主角克服阻碍加深感情
- 好感度进度条：每一步推进=升级文中的一个"等级"
- 每一个事件是一次"升级"→通过冲突、化解、理解和共鸣让好感攀升

**好感度升级案例**：
- 路人→好人（扶老奶奶过马路）
- 好人→正直勇敢的好人（挺身而出救她）
- 正直勇敢→不错的朋友（理解她的原生家庭困境）
- 不错的朋友→喜欢但不知（特殊契机看到彼此不为人知的一面）
- 关键：不要一步到位，双修解毒等偷懒写法=毒点

**关键原则：主角不主动追求**：
- 当前男频读者普遍反感"舔狗"人设
- 推动好感靠男主自身优秀品质吸引→不是主动追求
- 男主帮女主是举手之劳不经意为之→女主因此记住他

**感情升级的不对称性**：
- 两条进度线：表面社会关系（路人→朋友→情侣）+ 实际情感好感度
- 两条线不应齐头并进→一条快一条慢→带来丰富的矛盾冲突
- 情感线快于社会线→辉夜大小姐模式→双方好感拉满但嘴硬不表白
- 社会线快于情感线→赘婿/择天记模式→表面是夫妻但实际好感为零

**事业线不可或缺**：
- 仅靠恋爱元素很难写长→主角自我提升和事业发展是必需
- 女主对主角事业起到积极作用→不能割裂
- 女主可拥有独立事业线→与主角事业相辅相成→互动更有化学反应

**写女主对主角好**：
- 根据女主人设设计不同付出方式→不能千篇一律
- 自卑社恐→偷偷帮忙塞东西但害怕被发现
- 傲娇型→用心做便当但嘴硬"做多了顺便带的"
- 直率泼辣→大大方方送礼物或直球表白
- 成功女主人设的关键=对细节的刻画

**善用对比**：
- 时间线对比：女主刚认识主角时vs熟悉后的态度变化→一大爽点
- 双标：女主对主角的特殊待遇→不允许别人摸头但主角可以→凸显特殊地位
- 信息差：男女主双重身份（网上vs现实）→读者期待揭穿时的反应
- 新身份打破固有印象→让角色看到对方不为人知的另一面

**素材积累方法**：
- 多看小说/恋爱番/电影
- 知乎/微博/小红书搜"情侣甜蜜日常""女生心动瞬间"等话题
- 从高赞回答中摘录精彩片段做创作参考

## 恋爱文发布与冲榜攻略（恋爱文主题配套：发布/榜单/推荐/投稿）

### 起点榜单与冲榜策略

**新书四大榜单**（按难度和效果排序）：

| 榜单 | 收录条件 | 难度 | 效果 |
|------|----------|------|------|
| 公众作者新书榜 | 第二本及以上非签约作品，20万字以内，入库30天内 | 容易 | 较弱 |
| 新人新书榜 | 第一本非签约作品，20万字以内，入库30天内 | 中等 | 一般 |
| 新人签约新书榜 | 第一本签约作品，A签后30天内 | 较难 | 很好 |
| 签约作者新书榜 | 签约作者新书 | 最难 | 最强 |

- 榜单潜力值公式：当周会员点击 x 5 + 当周推荐 x 5 + 总收藏 x 2
- 冲榜时机：周一凌晨，多准备更新爆发，配合朋友投票
- **新人签约新书榜第一名效果最强**——会显示在每本书的章节末尾

### 推荐位效果排序

从强到弱：
1. 分类强推（效果最好）
2. 首页六频广告
3. 分类小说新书推荐（效果优于新闻位推荐）
4. 新书精选（封面足够吸引人时效果好）
5. 三江推荐（5万字后每周申请）

**推荐位获取关键**：
- 每本签约新书无条件拿到一个推荐，视成绩决定后续
- 合同到达时间尽量控制在周一或周二之前，这样改状态的那周就可能拿到推荐
- 推荐位总数有限，每个推荐质量都很重要
- 老作者待遇优于新人，但推荐安排大体公正

### 新人分类选择建议

| 分类 | 适合新人？ | 原因 |
|------|-----------|------|
| 都市 | 适合但难出头 | 语言生活化容易上手，但竞争激烈，读者挑剔 |
| 游戏同人 | 最适合练笔 | 世界观现成、读者忍耐度高、认可度好 |
| 仙侠/玄幻 | 不适合 | 玄幻分强只涨几千点击，新人容易被埋 |
| 历史 | 最难 | 创意要求高，分类凋零 |

**跟风 vs 创新**：
- 跟风：借鉴题材和创意，不少跟风作在原作太监后凭借坚持和笔力超越原作
- 创新：容易吸引读者和编辑目光，但一书成神运气因素超过实力
- **新人建议**：第一本书不要抱太大期望，运气的因素超过实力的影响

### 新人投稿流程

1. 先写三万字（不必先写大纲，新人签约比大纲重要）
2. 三万字不急着发网站，先投各买断网站邮箱和编辑内签邮箱
3. 综合审稿意见（排除机械化自动回复），修改完善
4. 没有内签消息再发网站，一天不超过8000字
5. 三万字没来站短，继续写到7-8万字还有一次机会
6. 十万字自己申请签约，还没来就可以考虑重新开始
7. 签约后关注《省钱攻略》，与责编保持适当沟通

## 装逼三层次与打脸三层次

> 新媒体装逼打脸的完整分类体系。从基础到终极，层层升级。

**装逼三层次**：

1. **基础装逼**：利用人的表现欲——很牛逼但无人知道，表现出来就是装逼
   - 不压，直接装。如黑社会来学校，主角站出暴打
   - 核心：表现欲→优越感

2. **温酒斩华雄式装逼**：基础装的升级版
   - 侧面烘托：配角突出华雄的牛逼→华雄突出主角的牛逼
   - 压得不重，一切服务于更好的装逼

3. **狠压式装逼**（核心中的核心）：温酒斩华雄再升级
   - 在第二层基础上，加大压强→压得上头→再装逼
   - 案例：关羽投靠华雄老大被赶走→投靠曹操被看不起→打杂→所有人都觉得他痴人说梦→一刀斩华雄
   - 核心：压的越狠，装逼越爽

**打脸三层次**：

1. **愤怒式打脸**：别人瞧不起主角+做了令读者上火的事
   - 核心是"瞧不起"，做的事情为打脸做准备
   - 单层次打脸：一次打完

2. **循环打脸**：一波接一波
   - 同一剧情打三四次，一波比一波爽
   - 案例：拆穿假画→奶奶偏袒说是真的→假画上写着中国制造→继续打脸

3. **终极打脸+装逼**：打脸和装逼结合
   - 案例：买车被鄙视→买下砸了→再买再砸→暴露身份→对方不敢收钱把钱送回来
   - 关键：但凡打脸剧情，狠压！压的越狠打脸爽度越强

**优越感的体现**：
- 装逼前=表现欲，装逼后=优越感
- 优越感无处不在：路人吹捧、女神爱慕、别人十年学成vs主角三天超越
- 随时随地秀优越——平淡过渡剧情也要体现优越感
- 被动装逼vs主动装逼：想低调但实力不允许 / 主动让你们见识真牛逼

**情绪的核心公式**：
- 装逼：利用优越感——我比别人档次高→我与众不同
- 打脸：利用解气——你瞧不起我→我碾压你
- 信息差是装逼打脸的倍增器——在合适时机加入信息差增强期待感

## 装逼打脸的人设铺垫法与前置小无敌

> 飞卢都市装逼打脸的完整实操体系。核心：铺垫比打脸重要，爽点=(人设+铺垫)+人物碰撞交织。

**装逼打脸三要素**：
1. **前置小无敌**：装逼场景开始前，把道具/人物/实力都准备好
2. **人设**：反派的性格特征（如狗眼看人低/势利眼/嚣张跋扈）
3. **铺垫**：用故事情节自然引出冲突（不是一句"你瞅啥"的硬凑）

**爽点公式**：
- 爽点 = (人设 + 铺垫) + 人物碰撞交织
- 人设和铺垫引出期待感→期待感被完整写出=爽点
- 不是打脸环节写不好，而是铺垫不够

**前置小无敌的具体操作**：
- 神豪文：系统签到几百亿→金钱无敌
- 都市修仙：武力碾压+提前布置权势人物（如魏老）→武力权势双无敌
- 洪荒文：系统/牛逼跟脚→身份无敌
- 关键：在装逼最关键的场景开始前，把打脸用的东西都准备好

**飞卢装逼打脸节奏模板**：
- 公众期5章循环：1章人设 + 2章铺垫 + 1章打脸 + 1章事后反响/收获
- VIP期拉长：1-2章人设 + 5章铺垫 + 1-2章打脸 + 1章事后总结
- 铺垫占比最大——这才是整个装逼打脸最核心的部分

**逼格法则**：
- 神豪和阿猫阿狗装逼=大忌→逼格不够
- 路人甲震惊≠读者爽→是作者自嗨
- 正确写法：让主角的逼格匹配对手的地位→大人物被震惊才有爽感
- 热点新闻当书名=把梗当同人写→自带铺垫好的故事，不需要额外铺垫

**铺垫≠过渡情节**：
- 误区：铺垫是过渡情节，能短则短
- 真相：铺垫本身可以就是故事，写好了读者以为在看故事其实在看铺垫
- 铺垫到位后，打脸环节200字就能让读者爽
- 案例：都市修仙KTV装逼，高潮部分千把字，但铺垫用了几万字

## 角色塑造深层技巧（移情/标签/聚光灯）

**移情作用="我能理解角色的动机"**：
- 读者理解角色深处动机→与角色位置重叠→发自内心期待后文→这是"合理性"的根源
- 没有移情的角色=读者不关心→牺牲无意义→涉险无意义→先做成角色再使用角色
- 开头不要出现太多角色→读者认知精力有限→在了解"发生了什么"之前不关心配角

**最小特征（标签法）**：
- 主角=由内而外塑造→内在根先塑造好→外在举动才合理→反差才有说服力
- 配角=由外到内→需要贴标签→"一个女孩"不好记忆→"一个胆怯怕生的小萝莉"就好记
- 标签利用读者已有"大脑缓存"→脑中破碎印象自发组合→看过的作品越多越新
- 标签化角色必然扁平→可完成剧情→但很难继续挖掘

**角色的不真诚（深化技巧）**：
- 人人戴面具→角色的所说≠所想→举动≠态度→外在≠内核
- 心死角色的笑声浸透悲伤→愤怒角色的平静意味更大风暴→潜台词是包装的礼物
- 深化两极：①单章日常→铁汉柔情/反派温情②发便当→角色深化源于死亡
- 警告：深化配角时主角不能欠缺→否则主角变单薄→读者感觉偏心

**聚光灯技巧（角色过多时）**：
- 一章前半是读者不关心的配角→难以集中注意力→最好不写→必须写则需准备聚光灯
- 聚光灯=让角色存在具有特殊意义→酝酿阴谋/与主角形成信息差/与主角紧密相关
- 临时主角=这一章的叙事中心→身份高的长老作为主镜头→快速叠标签→从一堆角色脱颖而出
- 配角压过主角→塑造新的友善/中立配角→夺走光环→找借口交还镜头给主角

## 角色移情与塑造体系

**角色移情作用**：
- 移情根本=读者能理解角色动机→读者与角色位置重叠→产生发自内心的深入探讨欲望
- **期待感来自移情**→移情也是剧情"合理性"的根源
- 没让读者记住的角色的牺牲毫无意义→使用角色前先"做成"一个角色
- 开头不要出现太多角色→读者认知精力有限→在了解"发生了什么"并期待"还要发生什么"之前→没有精力分给主角以外的角色

**角色最小特征（贴标签）**：
- 主角塑造由内而外→配角塑造由外到内→配角需要贴标签辅助记忆
- "一个女孩"不好记忆→"一个胆怯怕生的小萝莉"好记忆→利用读者"大脑缓存"
- 标签化角色是扁平的→可完成剧情但难挖掘→需进一步丰富

**角色的不真诚（深化手法）**：
- 人人都是不真诚的→角色的所说≠所想→举动≠态度
- 心死角色的笑声浸透悲伤→愤怒角色的平静意味着更大风暴→潜台词如包装的礼物
- **日常与便当=深化角色的两极**→日常=铁汉柔情→便当=死亡丰富形象
- 诡秘老尼尔→死前读者看到他的心/所爱/哭嚎/命运→角色立刻丰富
- 深化配角时注意不公平→配角充实化的同时主角不能变单薄

**角色聚光灯（多角色管理）**：
- 角色存在需具有特殊意义→酝酿阴谋/与主角强烈信息差/紧密相关→读者自然集中注意力
- 角色太多→选"临时主角"→这一章的叙事中心→叠标签使其脱颖而出
- 配角压过主角→塑造新配角夺走光环→找借口把镜头交回主角

## 高级爽点模板与生态位选题

**爽点模板（从棋子到棋手）**：
- 主角卷入高层博弈→争取到棋子位置→历经千辛万苦→终极一跃成为棋手
- 用平静写法映衬过去困难→塑造沉浸感更强的高潮→"诸位道友，贫道这方见礼了"
- 三大核心要素：①主体博弈大背景（设计几个超级boss从不下场）②中间奋斗的艰难（奋六世之余烈/十世登仙/卧薪尝胆）③高潮终极一跃（玄鉴天色既明/魔门十世登仙进位真君）

**生态位填补选题法**：
- 看平台过去爆款书完本后的生态位→没有书承接流量→读者书荒→你风格靠近写相似题材
- 如烂柯/高武/诡秘完本后的生态位→写得好未尝不能证道
- 或者空证→这条路没人走出大成绩→但思路没问题→受众足够→未尝不能晋位白金
