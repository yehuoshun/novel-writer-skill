# 书名查重（番茄小说上线前必做）

> 2026-10-11 老板定：书名定稿/上线前**必须查重**；设定撞车不是大问题（老板拍板），书名撞车才是真问题。

## 查重方法（2026-10-11 实弹验证）

1. **Exa 全网搜**：`mcporter call exa.web_search_exa query="\"书名\" 小说" numResults=8` + `"书名" 番茄`
2. **番茄站内近名**：`exa.web_search_exa query="site:fanqienovel.com 书名"`（番茄搜索页是 JS 渲染，web_fetch 拿不到结果，走 Exa site: 搜索）
3. 百度/必应中文搜索有验证码/广告污染，**不作主力**（实测必应返回广告、百度弹验证码）

## 判据

| 情况 | 处理 |
|------|------|
| 同名书存在（任何频道/平台） | **必换名**（实弹：《炼气一万年》撞 2020 女生频道老书，40 万字连载） |
| 近名/变体名已存在（炼气X万年、万古修仙：…炼气一万年） | 提醒+规避（实弹：番茄已有《炼气十万年仙人境界》《万古修仙：我在都市炼气一万年》） |
| 设定撞车（境界卡死+时间流逝梗相似） | 提醒但不阻断（老板拍板：设定撞车不是大问题） |

## 改名准则

- **保留分类关键词**：主角修炼体系词（炼气/修仙/剑修）——推荐算法分类靠它
- **保留核心卖点**：一万年→万古/老祖/老怪（避开「炼气一万年」直撞，梗还在）
- **长名转「又名」**：原长宣传名（如《关于我闭关一万年出关后发现全修仙界都在等我这件事》）转简介第一行「又名」，撞车风险低、引流保留
- 改名后全库同步：配置 info.name、简介、全书大纲、知识库名（yuque_update_repo name）、本地 outline 头部、记忆
